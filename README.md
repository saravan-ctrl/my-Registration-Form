# my-Registration-Form
A simple and responsive registration form built using HTML, CSS, and JavaScript. It validates user input and displays error messages when the entered information is invalid.
Registration Form

Project Description

A simple and responsive registration form built using HTML, CSS, and JavaScript. It validates user input and displays error messages when the entered information is invalid.

Technologies Used

- HTML5
- CSS3
- JavaScript

Features

- User name validation
- Email format validation
- Password length validation
- Error messages for invalid inputs
- Success message after successful validation
- Responsive and clean user interface

Project Structure

- "index.html" – Creates the registration form.
- "style.css" – Styles the form.
- "script.js" – Handles form validation.
- "README.md" – Provides project documentation.

How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html" in your browser.
4. Enter the details and click Register.

Learning Outcomes

- HTML form elements
- CSS styling and layout
- JavaScript DOM manipulation
- Form submission events
- Input validation
